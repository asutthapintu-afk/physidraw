# PhysiDraw — วาดไดอะแกรมฟิสิกส์

เว็บแอปวาดไดอะแกรมฟิสิกส์แบบลากวาง (แนวเดียวกับ BioRender) — ทัศนศาสตร์ วงจรไฟฟ้า กลศาสตร์ แม่เหล็กไฟฟ้า อุปกรณ์ห้องปฏิบัติการ เครื่องมือขั้นสูง และวัสดุศาสตร์

- ใช้งาน: https://asutthapintu-afk.github.io/physidraw/
- ส่งออก PNG / SVG / โปรเจกต์ .json
- งานบันทึกอัตโนมัติในเบราว์เซอร์ของผู้ใช้แต่ละคน

ทั้งเว็บอยู่ในไฟล์ `index.html` ไฟล์เดียว
